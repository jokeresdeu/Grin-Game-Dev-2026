# Лабораторна робота №4: Анімації в Unity

## Реалізовані анімації та логіка:

### 1. Вороги (Chicken) — Анімація смерті
* **Що зроблено:** При влучанні пташка плавно стискається в нуль і видаляється зі сцени.
* **Реалізація:** Створено кліп `Chicken_Die` через вікно Animation. В Animator налаштовано перехід через тригер, який викликається з коду скрипта в момент кліку по об'єкту.

### 2. Супер-атака (Chest) — Зміна стану та вибух
* **Що зроблено:** При активації скриня трясеться, різко збільшується в розмірах, фарбується в червоний колір (ефект вибуху) і зачищає екран від ворогів.
* **Реалізація:** Зроблено без Animator, суто процедурно через корутину в коді. Трясіння реалізовано мікро-зміщенням позиції, а збільшення та зміна кольору — через `Vector3.Lerp` та `Color.Lerp`.

### 3. Бонус (HealthKit) — Комбінована анімація
* **Що зроблено:** Замість стандартного квадрата додано зелену пташку. Вона постійно махає крилами, плавно хитається в повітрі і летить дзьобом уперед в обидва боки. При кліку видає великий зелений спалах і додає HP.
* **Реалізація:** Махи крилами крутяться через Animator (готовий кліп з ассет-паку). Покачування вгору-вниз прописано в коді через `Mathf.Sin(Time.time)`. Поворот спрайту реалізовано через `flipX` залежно від напрямку руху від точки спавну. При попаданні скрипт вимикає компонент Animator і через корутину роздуває `Scale` в **2.5** рази, переводячи колір у прозоро-зелений.

### 4. Екран поразки (LosePanel) — Поява UI
* **Що зроблено:** Вікно GameOver вилітає з ефектом пружини (Pop-up) при закінченні життів.
* **Реалізація:** Створено кліп `LosePanel_Pop`. Записано зміну `Scale` по ключових кадрах: на `0:00` — `0`, на `0:20` — `1.1`, на `0:30` — `1.0`. Панель активується через `ChickensManager`.

### 5. Приціл (Crosshair_01) — Елемент динаміки
* **Що зроблено:** Постійне зациклене обертання прицілу навколо своєї осі для покращення динаміки гри.
* **Реалізація:** Створено кліп `Crosshair_Spin`. Записано зміну параметра `Rotation Z` від 0 до 360 градусів за 2 секунди. В Animator цей стан стоїть за замовчуванням і зациклений (Loop Time).
