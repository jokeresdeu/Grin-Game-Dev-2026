Список доданих UI елементів:
Main Menu: Окрема сцена з фоном, логотипом та кнопками для старту гри та виходу.
Pause Menu: Внутрішньоігрова панель (активується на Esc), що дозволяє продовжити гру, перезапустити рівень або вийти в меню.
Heart-based Health Bar: Візуальна система життів на основі префабів сердечок замість звичайного тексту.
Score HUD: Оновлене відображення поточного рахунку.

Технічні деталі:
Navigation: Використано SceneManager для перемикання між сценами (налаштовано індекси у Build Settings).
Layout: Використано компонент Horizontal Layout Group для автоматичного вирівнювання сердечок.
State Management: Реалізовано керування ігровим часом через Time.timeScale (зупинка гри в меню паузи та програшу).
Code Architecture: Створено окремі класи MainMenu, PauseMenuController та HealthUI для розділення логіки інтерфейсу та гри.
