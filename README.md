# Chicken Hunt - Lab 5

Unity version: `Unity 6.3 LTS`

## How to run

Open the project in Unity and start the game from:

This is the main entry scene for Lab 5.

## Scene flow

- `MainMenu.unity` - main menu scene
- `lab4.unity` - Chicken Hunt gameplay scene

The expected play flow is:

1. Open `MainMenu.unity`
2. Press Play in Unity
3. Click `Play` to load the gameplay scene

## Notes

- The gameplay scene is located at `Assets/lab4.unity`
- Build Settings should keep `MainMenu.unity` first and `lab4.unity` second
