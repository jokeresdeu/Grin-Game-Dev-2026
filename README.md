# Ninja Kunai

## Опис
2D аркадна гра Ninja Kunai на Unity, де гравець керує ніндзя, який кидає кунаї в ящики що падають зверху.

## Геймплей
- Навколо ніндзя обертаються кунаї (максимум 4).
- Натискання ЛКМ — кидок кунаю у напрямку його вістря.
- Ящики мають міцність 1 або 2. При влученні гравець отримує 1 кунай назад.
- Коли всі ящики хвилі знищені — з'являється нова хвиля (від 1 до 4 ящиків).
- Гра закінчується, якщо всі кунаї витрачено і більше немає.

## Управління
| Дія | Кнопка |
|-----|--------|
| Кинути кунай | ЛКМ |
| Пауза | ESC |
