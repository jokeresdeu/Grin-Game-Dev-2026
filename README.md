# Звіт до лабораторної роботи: Adding mechanics to Chicken Hunt

## 3. Додані механіки взаємодії
У рамках виконання лабораторної роботи було додано наступні механіки:
1. **Життя (HP):** Додано систему здоров'я для гравця та ворогів. Здоров'я гравця відображається за допомогою UI `Slider` на екрані.
2. **Рахунок:** За вбивство ворогів гравець отримує монети, які збільшують рахунок. Рахунок відображається через UI `TextMeshProUGUI`.
3. **Умова програшу та перезапуск:** Якщо здоров'я гравця опускається до нуля, гра зупиняється (`Time.timeScale = 0`), активується UI-панель "Game Over", на якій присутня кнопка для перезапуску поточної сцени. Також реалізовано логіку перемоги (знаходження скрині).

## 4. Відповіді на запитання щодо системи стану гри

**1. Які типи колізій використані?**
В грі використані 2D колізії, що базуються на компонентах `Collider2D` (зокрема `BoxCollider2D` для гравця та скрині, а також для перешкод) у комбінації з `Rigidbody2D` (Dynamic для рухомих об'єктів і Static/Kinematic для оточення). Це дозволяє використовувати фізичний рушій для запобігання проходженню крізь об'єкти (твердотільні зіткнення).

**2. Де застосовано Raycast або Overlap?**
- **Overlap (`Physics2D.OverlapCircleAll`):** Застосовується для реалізації атаки гравця (Area of Effect). При натисканні кнопки атаки гравець створює віртуальне коло навколо себе і знаходить всіх ворогів (`RPGEnemy`) та інтерактивні об'єкти (`RPGChest`), яким завдається шкода або з якими відбувається взаємодія. Також цей метод використовується для знаходження найближчих NPC при натисканні клавіші взаємодії ('E').

**3. Чому саме такий метод перевірки обрано?**
- `OverlapCircleAll` було обрано для бойової системи та взаємодії, оскільки атака мечем діє по площі (сферичний замах зброєю навколо персонажа). Це дозволяє одночасно зачепити кілька цілей у зоні досяжності, що робить геймплей динамічнішим. Подальша математична перевірка напрямку (`Vector3.Dot`) дозволяє відфільтрувати ворогів, які знаходяться позаду гравця, роблячи удар логічним і реалістичним.

**4. Як механіки впливають на core loop?**
Механіки повністю формують *core loop* (основний цикл гри). Базовий цикл тепер виглядає так: *Рух та дослідження -> Зустріч з ворогами -> Боротьба за виживання (втрата HP) та збір нагород (Score) -> Досягнення мети (Скриня / Перемога) АБО Помилка (Game Over) і Перезапуск*. Наявність HP та Умови програшу додає виклик та ціну помилки, а наявність рахунку створює додаткову мотивацію. Усе це робить ігровий процес повноцінним і завершеним.
