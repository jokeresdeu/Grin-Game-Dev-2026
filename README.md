## Список доданих анімацій:
1. **Bird_Idle:** Постійна анімація польоту курки (спрайт-анімація).
2. **Bird_Death:** Анімація зникнення (Scale 0) курки при влучанні. Реалізовано керування через тригер `Die` у коді.
3. **LosePanel_Show:** Плавна поява панелі Game Over (Scale 0 -> 1). Налаштовано `Unscaled Time` для коректної роботи при зупинці часу.
4. **Score_Pop:** Ефект "підстрибування" тексту очок при зміні рахунку. Реалізовано через код `ChickensManager` та тригер `Pop`.
5. **Restart_Pulse:** Постійна пульсація кнопки перезапуску для покращення UI-фідбеку.

## Технічні деталі:
- Використано компоненти **Animator** та **Animation**.
- Налаштовано переходи (Transitions) між станами з використанням параметрів типу **Trigger**.
- Реалізовано затримку видалення об'єктів через `Destroy(gameObject, delay)`, щоб анімація встигла програтися.
