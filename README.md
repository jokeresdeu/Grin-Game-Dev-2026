# Лабораторна робота 4 - Анімації

У цій лабораторній роботі було реалізовано:

*   Зміна текстури модельки та додавання покадрової анімації до монет.
*   Додано можливість швидко бігати персонажу зажавши клавішу Shift (спринт).
*   Покращення штучного інтелекту ворогів — тепер вони більше не кучкуються в одній точці, а розподіляються.
*   Керування всіма ігровими анімаціями через C# код.
*   Інтегрування бібліотеки Spine у проєкт (додано Spine-об'єкт на сцену).

### Анімації ігрових об'єктів:

**Головний герой має анімації:**
- **Idle** (стан спокою).
- **Walk/Run** *(Уточнення: У самому коді для звичайної ходьби та бігу використовується одна й та сама анімація руху, але під час спринту C#-скрипт просто збільшує швидкість її відтворення в півтора рази `animator.speed = 1.5f`, що створює ефект швидкого бігу)*.
- **Attack** (удар мечем).
- **Die** (анімація падіння при смерті).

**Ворог (Wolf) має анімації:**
- **Idle** (стан спокою).
- **Walk** (рух у бік гравця).
- **Attack** (атака вовка)
- **Die** (відкидання та зникнення при смерті).

**Монета:**
- Має анімацію постійного кружляння (обертання навколо своєї осі).

**Скринька:**
- Має коротку анімацію взаємодії (анімація squash and stretch).
