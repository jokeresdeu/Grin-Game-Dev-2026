Лабораторна робота №6: Однокнопочна гра Ziggy

Опис гри Аркадний 3D-раннер, де все керування реалізовано однією кнопкою (клік миші або `Space`). Кожне натискання змінює напрямок руху куба на 90 градусів. 

Мета — втриматися на дорозі та збирати монетки. 

Реалізований функціонал:
1. Керування та рух: Автоматичний рух куба по сітці плиток із плавним перекочуванням. 
2. Спавнер дороги: Нескінченна генерація нових плиток дороги попереду гравця та випадковий спавн монеток. 
3. Елементи UI: Головне меню з кнопкою старту; Екран GameOver із виведенням фінального рахунку; Меню Паузи (на клавішу `Esc`) з кнопками продовження, перезапуску та виходу. 
4. Аудіо: Фонова музика в меню та грі, а також звук підбору монетки.
