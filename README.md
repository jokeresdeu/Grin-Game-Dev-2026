# Лабораторна робота №3: Реалізація ігрових механік у проєкті "Chicken Hunt"

**Студентка:** Ванжа Дарʼя Ігорівна

---

## Опис виконаної роботи
У межах лабораторної роботи №3 було реалізовано та налаштовано базові геймплейні механіки для гри "Chicken Hunt" у середовищі Unity.

### Основні результати:
* **Розробка ігрової логіки:** Створено C# скрипти для забезпечення механіки взаємодії з ігровими об'єктами (курами) та обробки користувацького вводу.
* **Налаштування компонентів:** Конфігуровано компоненти 2D-фізики (Rigidbody2D, Collider2D) та відображення спрайтів (SpriteRenderer) для коректної поведінки об'єктів на сцені.
* **Середовище розробки:** Додано конфігураційні файли .vscode та оновлено структуру рішення проєкту (.slnx) для забезпечення коректної збірки та дебагу на macOS.
