# Звіт по лабораторних роботах №3, №4 та №5

## Лабораторна робота №3 - Механіки взаємодії

**Мета:** Розширити прототип гри, додавши базові механіки взаємодії, використовуючи `Collider2D`, `Trigger`, `Physics2D.Raycast` та `Physics2D.Overlap*`. Ознайомитись із обробкою подій зіткнень та логікою взаємодії між обʼєктами.

**Реалізація:**

- Обрана гра: **Classic Platformer**  
- Додані мінімум 3 механіки взаємодії:  
  - Життя (HP) з індикатором у UI  
  - Система досвіду (EXP) та рівнів  
  - Умова смерті та перезапуск сцени
  - Ворог
  - Постійне отримання урону у вогні
- Типи колізій: `Collider2D` на гравці та ворогах, `OverlapCircle` для перевірки землі, стін та атаки на ворогів  
- Застосування `Raycast`/`Overlap`:  
  - `Physics2D.OverlapCircle` для визначення землі та стін  
  - `Physics2D.OverlapCircleAll` для визначення ворогів у зоні атаки  
- Обрана логіка `OverlapCircle` через простоту та ефективність для платформера  
- Вплив на core loop: механіки здоров’я, атаки та досвіду створюють основний цикл гри, дозволяють гравцеві отримувати зворотний зв’язок та стимул до дії

## Лабораторна робота №4 - Анімації в Unity

**Мета:** Додати анімації для гравця та об’єктів сцени, керуючи станами через код.

**Реалізація:**

- Проанімував мінімум 5 обʼєктів:  
  - Гравець: біг, стрибок, idle, пошкодження, смерть  
  - Вороги: атака, смерть, idle
  - Обʼєкти сцени: плавна idle анімація для лисття відновлення здоров'я, анімація пересування сходів.
  - Анімації меню (до 5 лабораторної)
- Керування анімаціями через `Animator` і код:  
  - Перемикання анімацій залежно від стану гравця (рух, атака, блок(тіки анімація, без логіки самого блоку), смерть)  
  - Виклик тригерів анімації при отриманні шкоди та смерті

## Лабораторна робота №5 - UI

**Мета:** Створити ігровий UI для індикації стану гравця та управління грою.

**Реалізація:**

- Додані UI елементи:  
  - Попередньо вже присутні індикатори здоров’я (HP) та досвіду (EXP) через `Image.fillAmount`  
  - Відображення рівня гравця через `TMP_Text`  
  - Меню смерті з кнопкою перезапуску сцени
  - Головне меню  
- Реалізовані класи для керування UI: `PlayerView` оновлює HP, EXP та рівень  
- Анімації і стан гравця синхронізовані з UI, що покращує зворотний зв’язок для гравця

---

**Висновок:**  
У рамках трьох лабораторних робіт реалізовано повний цикл взаємодії гравця з ігровим світом: рух, атака, отримання та відновлення здоров’я, набір досвіду, відображення стану через UI, анімації руху та реакції на події. Додаткові завдання на бонусні бали не виконувалися.
