Назва гри

Orbit Rush

Короткий опис гри

Orbit Rush — це 2D-гра, у якій гравець керує маленьким енергетичним шаром, що рухається по орбіті навколо центрального ядра. Завдання гравця — уникати шипів, збирати кристали та набирати якомога більше очок.

Механіка в одному реченні

Гравець одним кліком змінює напрямок руху персонажа по орбіті, уникає шипів і збирає кристали для збільшення рахунку.

Керування

У грі використовується лише одна дія:

ЛКМ — змінити напрямок руху персонажа по орбіті.
Core loop гри
Гравець запускає гру з головного меню.
Персонаж починає рухатися по орбіті навколо центрального ядра.
Гравець одним натисканням змінює напрямок руху.
На орбіті з’являються перешкоди та кристали.
Гравець уникає перешкод і збирає кристали.
За виживання та зібрані кристали збільшується рахунок.
З часом складність гри поступово зростає.
При зіткненні з перешкодою гра завершується.
Гравець може перезапустити гру або повернутися в головне меню.
Умова програшу

Гра завершується, якщо персонаж торкається шипа на орбіті.

Система прогресу

Прогрес гравця відстежується через:

поточний рахунок;
найкращий результат;
зібрані кристали;
поступове збільшення складності.
Основні елементи гри
головне меню з кнопками Play та Quit;
ігрова сцена з персонажем, центральним ядром, шипами та кристалами;
UI з поточним рахунком і найкращим результатом;
меню паузи з кнопками Resume, Restart, Quit;
екран програшу з можливістю перезапуску гри.
