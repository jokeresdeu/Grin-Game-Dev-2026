# Проєкт: Classic Platformer


## 1. Використані типи колізій

У проєкті я переважно використовував Trigger Colliders (Is Trigger) для всіх інтерактивних об'єктів:



Вороги та перешкоди: щоб гравець отримував шкоду, але не "застрягав" у них фізично.

Предмети (монети, аптечки): щоб вони спрацьовували при торканні та зникали.

Важіль та двері - для реєстрації того, що гравець підійшов достатньо близько для взаємодії.

## 2. Застосування Overlap та Raycast

У скрипті Player.cs я використав метод Physics2D.OverlapCircle.



Де застосовано? -  У методі Update для перевірки змінної _isGrounded.

Чому обрано саме цей метод? -  OverlapCircle дозволяє створити невидиму зону під ногами гравця. Це набагато надійніше за Raycast у платформерах, бо він краще обробляє краї платформ і не дає персонажу "зависнути" у повітрі, якщо він стоїть на самому краю.

## 3. Вплив механік на Core Loop

Основний цикл гри (Core Loop) став складнішим:



Ризик: тепер наш гравець може програти (рестарт рівня), якщо HP впаде до 0.

Дослідження: гравець не може просто пробігти рівень — йому потрібно знайти важіль, щоб відчинити двері.

Нагорода: збір монет додає мету — зібрати якомога більше очок перед фінішем.
