# Chicken Hunt

**Chicken Hunt** — це проста 2D-гра на Unity, у якій гравець повинен стріляти по птахах, що летять через екран, набирати очки та не допустити програшу.

## Опис гри

У грі птахи автоматично з’являються з різних точок спавну та летять у заданому напрямку.  
Гравець керує прицілом за допомогою курсора миші.

Основне завдання гравця — навести курсор на птаха та натиснути ліву кнопку миші. Якщо гравець влучає в птаха, він отримує очки. Чим швидше та точніше гравець реагує на появу птахів, тим більший результат він може набрати.

## Як грати

1. Запустити сцену гри.
2. Дочекатися появи птаха.
3. Навести курсор миші на птаха.
4. Натиснути ліву кнопку миші.
5. За успішне попадання гравець отримує очки.
6. Якщо HP гравця стає рівним нулю, з’являється екран Game Over.
7. Після програшу гру можна перезапустити.

## Керування

| Дія | Кнопка |
|---|---|
| Наведення на ціль | Курсор миші |
| Постріл | Ліва кнопка миші |

## Типи птахів

У грі використовується декілька типів птахів. Вони відрізняються швидкістю, кількістю очок та кількістю попадань, необхідних для знищення.

| Тип птаха | Кількість попадань | Швидкість | Очки |
|---|---:|---:|---:|
| Звичайний птах | 1 попадання | Середня | 100 |
| Великий птах | 2 попадання | Низька | 350 |
| Маленький птах | 1 попадання | Висока | 1000 |

### Звичайний птах

Звичайний птах є базовим типом цілі. Він має середню швидкість, знищується з одного попадання та дає гравцеві 100 очок.

### Великий птах

Великий птах рухається повільніше, але має більше здоров’я. Для його знищення потрібно влучити два рази. За великого птаха гравець отримує 350 очок.

### Маленький птах

Маленький птах рухається швидше за інші типи, тому влучити в нього складніше. Він знищується з одного попадання, але дає найбільшу кількість очок — 1000.

## Ігрова логіка

Птахи створюються автоматично через спеціальні точки спавну. Кожна точка спавну відповідає за позицію появи птаха та напрямок його польоту.

Менеджер гри випадковим чином обирає тип птаха зі списку доступних префабів. Після створення птах починає рухатися у заданому напрямку. Якщо гравець наводить курсор на птаха та натискає ліву кнопку миші, виконується перевірка попадання.

Коли кількість попадань досягає потрібного значення, птах знищується, а гравець отримує відповідну кількість очок. Якщо птах виходить за межі допустимої зони, він видаляється зі сцени, щоб не перевантажувати гру зайвими об’єктами.

## Основні скрипти

### Chicken.cs

Скрипт `Chicken.cs` відповідає за поведінку окремого птаха.

Основні функції скрипта:

- зберігає кількість очок за птаха;
- зберігає кількість попадань, необхідних для знищення;
- задає випадкову швидкість руху;
- керує рухом птаха по сцені;
- обробляє попадання;
- знищує птаха після потрібної кількості попадань;
- передає очки до менеджера гри.

Основні параметри в Inspector:

| Параметр | Опис |
|---|---|
| Points | Кількість очок за знищення птаха |
| Hits To Kill | Кількість попадань для знищення |
| Min Speed | Мінімальна швидкість руху |
| Max Speed | Максимальна швидкість руху |
| Sprite Renderer | Візуальний спрайт птаха |

### ChickensManager.cs

Скрипт `ChickensManager.cs` відповідає за основну логіку гри.

Основні функції скрипта:

- запускає спавн птахів;
- випадково обирає тип птаха;
- зберігає список активних птахів;
- нараховує очки;
- оновлює текст очок на екрані;
- контролює HP гравця;
- вмикає панель Game Over;
- перезапускає гру.

Основні параметри в Inspector:

| Параметр | Опис |
|---|---|
| Spawn Points | Точки появи птахів |
| Chicken Variants | Список доступних типів птахів |
| Min Spawn Time | Мінімальна затримка між появою птахів |
| Max Spawn Time | Максимальна затримка між появою птахів |
| Max Chickens | Максимальна кількість активних птахів на сцені |
| Kill Distance | Відстань, після якої птах видаляється |
| Score Text | Текст для відображення очок |
| HP Text | Текст для відображення здоров’я |
| Game Over Panel | Панель, яка показується після програшу |

### SpawnPoint.cs

Скрипт `SpawnPoint.cs` відповідає за точку появи птаха.

Він створює птаха у позиції об’єкта `SpawnPoint` і задає напрямок польоту.

Основний параметр:

| Параметр | Опис |
|---|---|
| Fly Direction | Напрямок польоту птаха |

Приклади налаштування напрямку:

```text
X = 1, Y = 0   — птах летить праворуч
X = -1, Y = 0  — птах летить ліворуч
```

## Налаштування птахів

Для кожного типу птаха створюється окремий prefab.

Приклад налаштувань:

### Chicken_Normal

```text
Points = 100
Hits To Kill = 1
Min Speed = 2
Max Speed = 5
```

### Chicken_Big

```text
Points = 350
Hits To Kill = 2
Min Speed = 1
Max Speed = 3
```

### Chicken_Small

```text
Points = 1000
Hits To Kill = 1
Min Speed = 6
Max Speed = 8
```

## Налаштування спавну

В об’єкті `ChickensManager` потрібно заповнити поле `Chicken Variants`.

Приклад:

```text
Element 0:
Prefab = Chicken_Normal
Weight = 70

Element 1:
Prefab = Chicken_Big
Weight = 20

Element 2:
Prefab = Chicken_Small
Weight = 10
```

Параметр `Weight` відповідає за шанс появи певного типу птаха. Чим більше значення, тим частіше буде з’являтися цей тип.

## Умови програшу

Головна мета гравця — набрати якомога більше очок.

Програш настає, коли HP гравця стає рівним нулю. Після цього на екрані з’являється панель Game Over, а гра зупиняється.

## Підсумок

**Chicken Hunt** — це проста аркадна 2D-гра на Unity, побудована на реакції та точності. Гравець наводить курсор на птахів, натискає ліву кнопку миші та отримує очки за попадання. Різні типи птахів роблять гру цікавішою: великий птах потребує двох попадань, а маленький птах летить швидше та дає більше очок.
