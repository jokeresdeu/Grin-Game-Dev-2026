## Опис проєкту
У межах цієї лабораторної роботи було розроблено двовимірну аркадну гру у стилі *Flappy Bird*, де реалізовано концепцію **однокнопкового керування**. Гравець керує персонажем (Angry Bird), який повинен маневрувати у повітрі та ухилятися від випадкових перешкод (космічного каміння), що летять назустріч із різною швидкістю та розміром.

### Ігрові механіки та правила:
* **Керування:** Виконується суто за допомогою **однієї кнопки** — клавіші `Space` (Пробіл) або лівого кліку миші. Кожне натискання додає імпульс пташці вгору.
* **Гравітація:** Постійно тягне персонажа вниз, змушуючи гравця безперервно підтримувати баланс.
* **Перешкоди:** Нескінченний спавн каміння, яке генерується на випадковій висоті справа за межами екрана, обертається навколо своєї осі та рухається вліво.
* **Система підрахунку очок:** За кожне каміння, від якого гравець успішно ухилився (об'єкт перетнув ліву межу екрана), нараховується `+1` бал.
* **Умова програшу:** Будь-яке зіткнення пташки з каменем (тег `Obstacle`) миттєво зупиняє ігровий час (`Time.timeScale = 0`) та викликає UI-панель **Game Over**.
* **Перезапуск:** На екрані програшу реалізовано функціональну кнопку **RESTART**, яка повертає ігровий час до норми (`Time.timeScale = 1`) та перезавантажує поточну сцену з нуля.

## Структура нових скриптів проєкту (`Assets/Scripts/OneButtonGame/`):
1. `FlappyPlayer.cs` — відповідає за фізику стрибка пташки від однієї кнопки та відслідковування колізій із перешкодами.
2. `FlappyManager.cs` — керує станами гри (старт, пауза, програш), оновлює TextMeshPro рахунку та перезапускає сцену через SceneManager.
3. `StoneSpawner.cs` — таймерний генератор префабів каміння з випадковим масштабом (від 0.6 до 1.4) та випадковою позицією по осі Y.
4. `StoneMover.cs` — забезпечує рух перешкод вліво, їхнє постійне кручення навколо своєї осі та нарахування балів у разі успішного прольоту повз гравця.
