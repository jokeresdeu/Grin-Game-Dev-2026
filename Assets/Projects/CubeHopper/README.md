## Опис гри

**CubeHopper** — це 2D-раннер з однією дією у стилі *Geometry Dash*. Куб автоматично біжить праворуч світом, що нескінченно генерується, гравець керує ним лише одним натисканням.

### Механіка одним реченням

> Натисни **будь-яку кнопку (Space / ЛКМ / тап)**, щоб куб стрибнув над шипом — без натискання він біжить далі, з трьома хітами і прогресуючою швидкістю.

### Чому це "однокнопкова" гра

Гравець виконує **рівно одну дію** — стрибок. Усі інші системи (рух уперед, прискорення, спавн перешкод, нарахування очок, комбо-множник) виконуються автоматично грою. Жодна друга кнопка не використовується для геймплея.

## Core loop

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   1. Куб біжить праворуч з постійним прискоренням           │
│              ↓                                              │
│   2. Гравець бачить шип і тапає                             │
│              ↓                                              │
│   3. Куб стрибає, перелітає перешкоду                       │
│              ↓                                              │
│   4. За кожну пройдену перешкоду — комбо-множник (×1..×5)   │
│              ↓                                              │
│   5. Швидкість + щільність шипів зростають з часом          │
│              ↓                                              │
│   6. При зіткненні з шипом гравець втрачає 1 з 3 життів     │
│      + комбо скидається, ненадовго увімкнено інвулнерабіліті│
│              ↓                                              │
│   7. Після 3-х зіткнень — Game Over, найкращий рахунок      │
│      зберігається в PlayerPrefs                             │
│              ↓                                              │
│   8. Можливість перезапуску або повернення в головне меню   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## Особливості (унікальні фішки)

- **Комбо-множник x1..x5** — за кожну пройдену перешкоду накопичується прогрес комбо; на максимумі очки нараховуються в 5 разів швидше. Удар скидає комбо, що додає реальної ваги ризику.
- **3 життя + інвулнерабіліті** — гра не one-shot, як класичний Geometry Dash; гравець має 3 спроби з коротким часом невразливості після хіта (видно через мерехтіння спрайту).
- **Адаптивна швидкість світу** — швидкість збільшується з часом (`_accelerationPerSecond` у `WorldSpeed`), а перешкоди починають спавнитись щільніше — динамічна крива складності, не лінійна.
- **Slowdown на хіт** — короткочасне сповільнення світу (50%, 0.6с) додає кінестетичний фідбек, не зупиняючи гру.
- **Колір фону залежить від швидкості** — gradient interpolation у `BackgroundColorShifter` робить світ "напруженішим" по мірі прискорення.
- **Camera shake** — Perlin noise based shake при ударі — без gimbal lock, без раптових стрибків.
- **Coyote time + jump buffer** — гравець може стрибнути в межах 80 мс після того, як впав з краю, і натискання за 120 мс до приземлення зберігається — стандарт індустрії для платформерів, відчувається набагато краще, ніж "чистий" frame-perfect стрибок.
- **Variable jump height** — короткий тап = маленький стрибок, утримання = вищий (через `_fallMultiplier` і `_lowJumpMultiplier`).
- **Trail з кольорами на комбо** — `TrailRenderer` змінює gradient і lifetime, коли активне комбо.
- **Найкращий рахунок зберігається** через `PlayerPrefs` між запусками гри.

## Керування

| Дія | Кнопка |
|-----|--------|
| Стрибок | `Space` / `LMB` / `Touch` / `↑` / `W` |
| Пауза | `Escape` |
| Рестарт (в Game Over) | `Space` / `LMB` / `Touch` |
| Повернення в меню (в Game Over) | `Escape` |
| Старт у Main Menu | `Space` / `LMB` / `Touch` / `Enter` |

> Гра використовує **рівно одну дію (натискання)** під час геймплея — клавіша паузи `Escape` зарезервована для системної функції зупинки гри.

## Архітектура коду

19 файлів `.cs`, ~1290 рядків, без зовнішніх залежностей крім TMP / UGUI:

| Файл | Призначення |
|------|-------------|
| `GameManager.cs` | Singleton + state machine (`Playing`/`Paused`/`GameOver`), завантаження сцен, пауза, рестарт |
| `GameState.cs` | Enum гри |
| `WorldSpeed.cs` | Singleton — поточна швидкість світу, прискорення, slowdown на хіт |
| `ScoreManager.cs` | Очки, комбо-множник, best score у `PlayerPrefs` |
| `PlayerController.cs` | Введення, фізика стрибка, ground check, coyote time, jump buffer, обертання |
| `PlayerHealth.cs` | Життя, інвулнерабіліті, події `Damaged` / `Died` |
| `PlayerCollision.cs` | Колізії гравця з тегом `Obstacle`, knockback, shake |
| `PlayerTrailPulse.cs` | Зміна gradient на TrailRenderer від комбо |
| `ObstacleSpawner.cs` | Зважений спавн перешкод з прогресуючою щільністю |
| `ObstacleMover.cs` | Рух перешкоди ліворуч + нарахування комбо при проходженні |
| `ObstacleLifecycleNotifier.cs` | Event `Destroyed` для лічильника `ObstacleSpawner` |
| `GroundScroller.cs` | Tiled tileable ground з recycle threshold |
| `ParallaxLayer.cs` | Параллакс шар з recycle |
| `CameraShake.cs` | Perlin noise shake (unscaled time) |
| `BackgroundColorShifter.cs` | Колір фону камери залежно від швидкості |
| `HUDController.cs` | Текст рахунку, best, комбо, іконки життів |
| `MainMenuController.cs` | Головне меню — натискання → старт |
| `PauseMenuController.cs` | Тогл паузи на `Escape` + кнопки Resume/Restart/Menu/Quit |
| `GameOverUI.cs` | Екран Game Over + кнопки Restart / Menu / Quit |

## Умова програшу та перезапуск

- **Програш:** після **3-х** дотиків до об'єкта з тегом `Obstacle` — `PlayerHealth.Lives` стає 0 → подія `Died` → `GameManager.TriggerGameOver()` → переключається стан на `GameOver` → `GameOverUI` показує панель з фінальним рахунком, найкращим рахунком та значком *NEW BEST*, якщо побитий рекорд.
- **Перезапуск:** будь-яке натискання на екрані Game Over (після 0.5 с lock) перезавантажує сцену — `SceneManager.LoadScene(currentScene)`. Або кнопка `Restart` миші. Або з паузи — `Restart` на панелі.
- **Повернення в меню:** `Escape` на Game Over або кнопка `Main Menu`.

## Як запустити

1. Відкрити проєкт у **Unity 6 (6000.0.x)** або новіше.
2. Відкрити сцену `Assets/Projects/CubeHopper/Scenes/CubeHopper_MainMenu.unity`.
3. Натиснути ▶ (Play).
4. У головному меню натиснути будь-яку кнопку → почнеться гра.
5. У грі — натискати на стрибок, уникати шипів, виживати якомога довше.
