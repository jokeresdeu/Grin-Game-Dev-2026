# Cup Game - Лабораторна робота №6

## Опис гри та Механіка
**Cup Game** - це прототип "однокнопкової гри", заснований на класичній грі в наперстки. 

**Механіка в одному реченні:** Гравець повинен уважно стежити за кулькою під час швидкого перемішування склянок і зробити лише один клік (натискання) по правильній склянці, щоб перейти до наступного раунду.

Гра має чіткий **Core Loop**:
1. Кулька ховається під однією зі склянок.
2. Відбувається швидке перемішування (швидкість залежить від вашого рахунку та обраної складності).
3. Гравець робить **єдину дію (один клік ЛКМ)** по обраній склянці.
4. Якщо вгадав - отримує очко і починається новий раунд (швидкість перемішування зростає). Якщо ні - втрачає життя.

## Основні елементи та Умови програшу
- **Індикатори (UI):** 
  - **Рахунок (Score):** Відстежує прогрес гравця. Чим вищий рахунок, тим швидшою стає гра.
  - **Здоров'я (Hearts):** У гравця є 3 серця (права на помилку).
- **Умова програшу (Game Over):** Коли гравець помиляється 3 рази і втрачає всі життя, гра закінчується. З'являється вікно програшу з фінальним рахунком і можливістю рестарту.
- **Внутрішньоігрове меню (Пауза):** Натискання `Escape` під час гри викликає меню паузи, яке дозволяє повернутися до гри (Resume) або вийти в головне меню (Quit).
- **Головне меню:** Стартова сцена гри, де гравець може вибрати складність гри перед початком та налаштувати її.

## Унікальні особливості (на додаткові бали)
- **Три рівні складності:** 
  - Easy (2 склянки) - для розминки.
  - Medium (3 склянки) - класика.
  - Hard (4 склянки) - для найуважніших хардкорних гравців.
- **Динамічна прогресія:** Швидкість анімації перемішування плавно і неперервно зростає з кожним вгаданим стаканом, перевіряючи реакцію гравця.
- **Режим тестування (ShowRightCup):** У головному меню є приховані налаштування (меню Settings), де можна ввімкнути "ShowRightCup" - правильна склянка завжди буде підсвічена зеленим кольором (функція створена спеціально для дебагу та перевірки логіки гри).

## Керування
- **ЛКМ (Ліва кнопка миші)** - єдина кнопка, яка потрібна для самого ігрового процесу (один клік для вибору).
- **Escape** - пауза під час гри.
