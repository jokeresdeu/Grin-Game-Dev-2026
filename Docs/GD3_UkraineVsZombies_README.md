# Лабораторна робота №3 - Механіки взаємодії

## Назва гри

Ukraine vs Zombies

## Мета роботи

Розширити існуючий прототип гри механіками взаємодії через Collider2D, Trigger та Physics2D. Додати систему здоров'я бази, рахунок, умову програшу, перезапуск сцени та UI-індикатори.

## Реалізовані механіки

1. Base HP

База має запас здоров'я. Якщо зомбі проходить до лівого краю карти, він наносить базі шкоду. Значення HP виводиться через текст і Slider.

2. Score

За кожного знищеного зомбі гравець отримує очки. Рахунок оновлюється в UI.

3. Game Over

Коли HP бази дорівнює нулю, гра переходить у стан програшу. Спавн ворогів і оновлення логіки гри зупиняються, а на екрані з'являється Game Over Panel.

4. Restart

На екрані програшу додано кнопку Restart. Вона викликає метод RestartScene() у GameManager та перезапускає поточну сцену.

5. Пошук ворогів через Overlap

Башта використовує Physics2D.OverlapCircleAll для пошуку ворогів у радіусі атаки. Знайдений ворог стає ціллю для пострілу.

## Типи колізій

Collider2D використовується у ворогів, башт та снарядів. Він потрібен для фізичного визначення зон взаємодії.

Trigger використовується для моменту, коли ворог входить у зону башти. У Enemy.cs метод OnTriggerEnter2D визначає башту, яку зомбі може атакувати.

Projectile використовує OnTriggerEnter2D, щоб визначити попадання у цільового ворога та нанести йому шкоду.

## Де застосовано Physics2D.Overlap

У Tower.cs додано метод FindTargetWithOverlap(). Він викликає Physics2D.OverlapCircleAll навколо башти та шукає ворогів у межах радіуса атаки.

Цей метод обрано тому, що башті потрібно перевіряти не одну точку, а цілу область навколо себе. OverlapCircleAll добре підходить для пошуку всіх потенційних цілей у зоні дії.

## Вплив механік на core loop

Core loop гри:

```text
Поставити башту -> дочекатися хвилі зомбі -> башта атакує ворогів -> зомбі або гине, або доходить до бази -> рахунок або HP бази змінюються -> гравець ставить нові башти
```

Score мотивує гравця знищувати більше ворогів. Base HP створює тиск, бо пропущені зомбі наближають програш. Game Over і Restart формують короткий цикл повторної спроби.
